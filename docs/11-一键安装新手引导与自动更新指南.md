# 一键图形化安装、首次使用新手引导与控制台自动升级指南

本文档面向希望**零命令行快速上手**的普通用户与需要了解底层安全保障的开发者，详细说明 LeaderTeam 的一键图形化安装器、三步新手配置向导，以及双发行分支隔离的自动检查更新与无损回滚机制。

---

## 一、统一跨线下载安装器（LT / OLT × Windows / Linux 四线合一）

无需手动查找 DSH 安装目录、无需手动下载多个配套文件，也不需要记忆 `dsh plugin` 命令：

1. **三种零门槛启动方式（任选其一）**：
   - **Windows PowerShell 一条命令（推荐）**：
     ```powershell
     irm https://raw.githubusercontent.com/youzi-ovo-create/dsh-leaderteam-releases/main/install-leaderteam.ps1 | iex
     ```
   - **Windows 单文件双击（零命令行）**：在 Release 页面只下载单个 **`Install-LeaderTeam.cmd`**，直接双击即可自动拉取统一下载器本体并打开浏览器向导（即使电脑未单独安装 Node.js，也会自动复用官方 DeepSeek Harness 桌面端内置运行时；若本机尚未安装 DSH，会给出清晰的官方下载指引 `https://deepseekdsh.com`）。
   - **Linux / WSL2 一条命令**：
     ```bash
     curl -fsSL https://raw.githubusercontent.com/youzi-ovo-create/dsh-leaderteam-releases/main/install-leaderteam.sh | bash
     ```
2. **向导自动完成的核心步骤**：
   - **自动识别平台与 DSH 环境**：自动识别 Windows/Linux 及架构、扫描本机已安装的官方桌面客户端（含自定义盘符目录如 `D:\Apps\DeepSeek-Harness`）与 CLI/Web 环境，已安装 DSH 直接复用；检测到 DSH 正在运行时提供 **「一键安全关闭 DSH」** 按钮；自动清理旧版 V2.1 遗留补丁。
   - **产品线、版本与修复安装选择**：支持自由选择 **Leader Team (LT · 闭源免费版)** 或 **Open Leader Team (OLT · 开源版)**、实时从官方 Releases 选择最新版或任意历史版本、选择 **修复安装** 或加载本地 `.tgz` 离线包，并自动执行 `SHA-256` 强校验。
   - **旧版 LT / OLT 品牌识别与防误切守卫**：自动识别当前环境已安装的 LT（`v2.3+`）或 OLT（`v2.2.x`）轨道并默认沿用原产品线；若主动跨线切换（LT ⇄ OLT）强制二次确认，全程保留 `<DSH_HOME>/leaderteam/` 中的本地配置、凭据、会话覆盖与历史数据。
   - **一键直启客户端**：安装完成后点击 **“立即启动 DeepSeek Harness 客户端”**，即可进入控制台；后续版本升级直接复用工作台内 **「设置 → 版本更新与兼容」** 自动更新机制。

## 二、进入控制台后：接入 Magpie 或任意模型供应商（预设 + 全量自定义）

进入 `/lt/` 原生工作台后，既可通过首次弹出的三步新手引导快速起手，也可直接在左侧栏 **「接入 → 供应商与 Key」** 完成全部模型与网关接入：

1. **Magpie 本机自动发现与一键接入（同时保留远程手动接入）**：
   - 打开「接入 → 供应商与 Key」，顶部 **「Magpie 网关快速接入」** 卡片会自动安全探测本机回环端口（`3425` / `8317` / `8080` / `3000` / `18080` 及环境变量/本地配置，绝不扫描公网且自动排除 LT 内置网关）；
   - 发现本机 Magpie 后点击 **「一键接入」**（若启用了鉴权，在弹窗中填入 API Key 后点「立即接入」），系统自动拉取可用模型并配齐全部角色，空闲会话立即生效；
   - 如需接入远程 Magpie 或其他 OpenAI/Anthropic/Gemini 兼容网关，点击 **「手动接入远程 Magpie」**，自由选择 **直连 DSH 原生通道（保留 `/quota`）** 或 **经 LT 内置网关托管（多 Key 故障切换与 120s 首包保护）**。
2. **常用供应商预设（保留 100% 自定义灵活性）**：
   - 点击右上角 **「添加供应商」**，可点选 **DeepSeek 官方、阿里云百炼 (DashScope)、智谱 BigModel (GLM)、OpenAI 官方、Anthropic 官方、Google Gemini、OpenRouter、远程 Magpie** 等预设一键填表，也可点击 **「自定义」**；
   - 所有字段（供应商标识、显示名称、4 种上游协议、Base URL、只写 API Key、多 Key 优先级、手动补充模型及 7 角色逐跳备用链）均保持完全可编辑自定义；勾选「保存后自动发现模型并加入统一模型池」即可免手动抄写模型 ID。

### 首次使用三步新手引导（Onboarding Wizard）

首次打开 `/lt/` 原生工作台（或随时点击底部状态栏 **「新手引导」** / 按 `Ctrl+K` 搜索 `新手引导`），系统同样提供交互式三步向导：

1. **第 1 步 · 免命令行接入模型 Key**：点选 DeepSeek、阿里云百炼（Qwen）、智谱（GLM）或 OpenAI，直接粘贴 API Key（自动安全保存至 `<DSH_HOME>/.credentials.yaml` / `.env` 本地 `0600` 凭据层，即时生效，绝不回传明文）。
2. **第 2 步 · 选择团队协作模式**：一键选择 **「标准自治团队（推荐）」**、**「轻量单兵模式（Single）」** 或 **「高并发深审团队」**，自动写入全 7 角色路由与执行池。
3. **第 3 步 · 创建并发送第一个任务**：点选内置开箱任务模板（如项目结构导览、代码健康巡检），一键自动创建 `leaderteam` 预设会话并开始执行。

## 三、控制台自动检查更新、一键升级与回滚

在 `/lt/` 工作台 **「设置 → 版本更新与兼容」**（或 DSH 侧边栏 **「LeaderTeam → 版本更新与新手引导」**）中内置完整桌面级升级体验：

- **自动检查新版本并展示更新说明**：启动控制台时按缓存周期后台静默检查更新，发现新版本后在底部状态栏提示 **「新版本 vX.Y.Z · 点击升级」**，并完整展示 GitHub Release 更新日志。
- **一键下载、SHA-256 校验与无感热升级**：
  - 自动核对 `SHA256SUMS.txt` 或资产摘要，校验不通过立即中止并清理临时文件；
  - **升级前自动检查 DSH 宿主兼容性**：若目标新包不兼容当前运行的 DSH 版本，将在改动任何文件前提前拦截提示；
  - 在 `dsh web`（HMR 模式）下点击升级后自动热替换生效，无需打开终端、无需手动重启进程；在官方桌面端下自动完成替换并提示下次重启生效。
- **100% 保留配置与历史数据 + 失败自动回滚**：
  - 用户模型配置（`leaderteam.local.json`）、本地凭据、历史会话记录（`<DSH_HOME>/sessions`）与团队账本（`<DSH_HOME>/leaderteam/teams`）均独立存放在用户数据目录，升级过程完整保留；
  - 每次升级前自动在 `<DSH_HOME>/leaderteam/updater/backups/` 创建完整离线备份快照；一旦安装异常将**自动回滚至原版本**，也可随时在设置页手动点击 **「一键回滚」**。
- **开源版与闭源免费版隔离检查 + `windows-vX.Y.Z` / `linux-vX.Y.Z` 双平台分轨匹配**：
  - **开源维护版**（`Apache-2.0`）仅默认检查 [`youzi-ovo-create/dsh-leaderteam`](https://github.com/youzi-ovo-create/dsh-leaderteam)；
  - **闭源免费公开发行版**仅默认检查 [`youzi-ovo-create/dsh-leaderteam-releases`](https://github.com/youzi-ovo-create/dsh-leaderteam-releases)；
  - **按操作系统自动识别平台专属 Release**：支持 `windows-vX.Y.Z` 与 `linux-vX.Y.Z` 独立发布节奏（向后兼容历史通用 `vX.Y.Z` 标签），Windows 客户端自动筛选 `windows-v*` 发行包、Linux 客户端自动筛选 `linux-v*` 发行包，严格阻断跨系统误装；
  - 未经用户显式勾选风险确认令牌，后端硬性拒绝跨分支升级（`409 TRACK_SWITCH_CONFIRMATION_REQUIRED`），杜绝误切换发行轨道。

## 四、零配置自动继承 DSH 模型、空闲即时生效与会话级独立配置

无需手工编写复杂 JSON，也不会再因在对话界面手动切换模型而报错：

1. **零配置自动继承 DSH 已配模型（以及「✨ 一键自动配齐角色」）**：
   - 若您已在 DeepSeek Harness 宿主设置中配置好任意模型（如通义千问、智谱 GLM、DeepSeek、OpenAI、Claude 等），首次启动 LeaderTeam 时会自动识别并生成本机角色覆盖（`leaderteam.local.json`），也可随时在接入或角色配置页点击 **「✨ 一键自动配齐角色」**。
   - 非 Magpie 直连的 OpenAI / GPT 模型在未配置外部配额文件（`quota.stateFile: null`）时直接放行；切换角色模型时自动对齐推理档位（`effort`）并自动解除被禁用模型家族限制。
2. **手动切换模型与推理档位自动跟随（默认 `leaderModelPolicy: "follow"`）**：
   - 在 DSH 原生聊天框或工作台手动切换当前会话的模型或推理档位（Reasoning Effort）时，LeaderTeam 会**自动同步至当前会话配置**，不再弹出“模型不一致”拦截报错。
   - 若您需要严格锁定配置模型，仍可在全局或单会话配置中主动切换为 `enforce`（严格锁定）或 `warn`（仅提示）。
3. **会话级独立隔离 + 空闲立即生效 / 执行中安全边界切换**：
   - 点击工作台顶栏 **「本会话配置」** 修改模型或策略时，默认**仅作用于当前会话**（保存在 `$DSH_HOME/leaderteam/session-configs/`），绝不污染全局默认配置或其他会话（除非主动点击「同步设为全局默认」）。
   - **空闲会话立即生效**：无论是单会话修改还是保存全局配置，所有处于空闲态的已有会话**当场立即生效**，无需重新新建会话；
   - **执行中会话安全边界切换**：若当前会话正在运行或有在途子代理，修改会自动暂存并在当前回合/子代理到达安全边界后平滑切换，绝不打断在途调用。
4. **严格的 User / Agent 权限分离**：
   - 仅允许**用户主动操作**（UI 控制台、DSH 模型选择器、CLI）修改全局或会话配置；Agent 执行体及工具调用被权限校验（`403 AGENT_CONFIG_MUTATION_FORBIDDEN`）与安全门硬规则（`protected-lt-config`）双重物理拦截，严禁模型自行篡改治理配置。
